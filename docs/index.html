the upz thesis

A linker already computes, for every byte, its final address and relocated value. upz keeps those facts as a first-class layout plan, packs sections in 4096B QAT windows during layout, and seals each pass inside a 64-byte cache-line-aligned LitanyWireFrame at gate 0x62.
